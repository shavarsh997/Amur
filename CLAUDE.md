## Как ты работаешь
- Ты оркестратор. Планируешь, пишешь задания, принимаешь работу.
  Код сам не пишешь: отдаёшь агенту builder. Исключение: правка в одну-две строки.
- Задание для builder не длиннее 10 строк, по шаблону:
  Цель: что сделать, одним предложением.
  Прочитай: какие файлы.
  Не трогай: какие файлы.
  Done when: команда, которую можно запустить, и что она должна показать.
- Независимые задания, которые не трогают одни и те же файлы, можно отдавать нескольким builder одновременно.
- Перед приёмкой сам запускаешь команду из Done when. Докладу builder на слово не веришь.
  Не прошла: возвращаешь задание builder с выводом ошибки. После трёх возвратов остановись и спроси меня.
- Когда вся задача принята, вызови reviewer: передай ему задания и попроси сверить изменения.
- Начало сессии: прочитай docs/progress.md и docs/known-issues.md.
- Конец задачи: допиши строку в docs/progress.md. Новое решение запиши в docs/decisions.md, новую ловушку в docs/known-issues.md.
- Папка acceptance/ это условие готовности от человека. Не меняй её сам и не давай менять builder.

## Проект и проверки
- Сайт SHINEX (www.shinex.am): Next.js 16 + React 19 + Tailwind 4, языки hy/ru/en/de/fr; контент и цены в `config/`, тексты в `messages/`. Репозиторий публичный.
- Проверки для Done when: `npm run lint`, `npm run typecheck`, `npm run build`, `npm run seo:check`, `npm run leads:check`, `npm run analytics:check`, `npm run calculator:check`; агент: `npm --prefix marketing-agent run test`.
- `sites/` — отдельный проект со своим git, к этому сайту не относится.
- `.claude/settings.json`: секреты закрыты deny-правилами, коммит с секретом блокирует хук `.claude/hooks/block-secret-commit.sh`. Не обходить.
