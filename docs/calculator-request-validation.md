# Заявки из калькулятора SHINEX

Дата проверки: 17 октября 2026 г.

## Поведение

1. На странице `/[locale]/calculator` пользователь выбирает строительство или дизайн и заполняет параметры.
2. Кнопка «Запросить расчёт стоимости» проверяет параметры и открывает существующее окно контактов сразу с формой заявки.
3. Параметры автоматически сохраняются в заявке; их можно просмотреть в раскрывающемся блоке. Для дизайна пользователь дополнительно указывает тип объекта.
4. Пользователь вводит имя, телефон, регион и необязательный комментарий.
5. Server Action повторно проверяет параметры и контакты. Существующая Telegram-интеграция отправляет контакты, площадь, выбранный пакет, конструкцию, форму дома и дополнительные условия.
6. Подтверждение показывается только после успешного ответа Telegram. При ошибке введённые данные сохраняются для повторной отправки. Ожидание Telegram ограничено 15 секундами.

Автоматическая сумма больше не открывается из калькулятора. Тарифы и существующий вычислительный модуль не изменялись. Сценарий ремонта по-прежнему предлагает обратиться в SHINEX; автоматический калькулятор ремонта не добавлялся.

## Проверки

- `npm run leads:check`: строительство и дизайн на пяти языках; все выбранные параметры; ограничения данных; неверные контакты и JSON; honeypot; обычная заявка; ошибки HTTP, Telegram API, сети, таймаут и отсутствие настроек. Проверяется также лимит длины Telegram-сообщения с максимальным комментарием.
- `npm run calculator:check`: существующие шесть сценариев строительства/дизайна на пяти языках и запрет автоматического расчёта ремонта.
- `npm run typecheck`, `npm run lint`, `npm run build`: успешно.
- `npm run seo:check -- --base-url http://127.0.0.1:3027`: 120 страниц, 50 вариантов старых URL, три редиректа со слешем, 15 ответов 404, внутренние ссылки, hreflang, структурированные данные и изображение для публикаций.
- Сравнение HTML с предыдущим SEO-снимком: canonical, hreflang, title, H1, robots.txt и sitemap.xml прежние на всех 120 маршрутах. Изменены только описания пяти языковых версий калькулятора; обычные страницы сохраняют свои метаданные.
- Браузер: обязательная площадь; открытие формы вместо цены; обязательные контакты; ошибка доставки с сохранением данных; повторная отправка; подтверждение успеха; дизайн с выбранным типом объекта; обычное обращение после калькулятора; сохранение площади при закрытии формы.
- Мобильный экран 390 × 844: все пять языков, одно окно заявки, без горизонтального переполнения.

## Граница проверки

Переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` присутствуют в локальном окружении. Их значения не изменялись и не выводились. Автотесты и проверка браузера использовали фиктивные учётные данные и локальную подмену ответа Telegram вне файлов приложения. Реальных тестовых сообщений в Telegram не отправлялось; доставка в рабочий чат и состояние production-окружения не проверялись. Изменения не развёртывались на production.
