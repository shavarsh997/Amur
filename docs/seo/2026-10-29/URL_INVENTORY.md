# Автоматический инвентарь URL

Команда: `node scripts/seo-inventory.mjs [HTTP-report.json]`. 120 URL в sitemap. Метрики — точные строки листа «Страницы»; отсутствие строки не равно нулю. Решение REDIRECT означает сохранение существующего правила. INVESTIGATE не меняет статус. Raw metadata, canonical, входящие страницы и статусы — в JSON; null означает, что HTTP-проверка ещё не приложена.

## Файлы маршрутов

- `app/[locale]/[landing]/page.tsx`
- `app/[locale]/about/page.tsx`
- `app/[locale]/blog/[slug]/page.tsx`
- `app/[locale]/blog/page.tsx`
- `app/[locale]/calculator/page.tsx`
- `app/[locale]/contacts/page.tsx`
- `app/[locale]/page.tsx`
- `app/[locale]/privacy/page.tsx`
- `app/[locale]/projects/[slug]/page.tsx`
- `app/[locale]/projects/page.tsx`
- `app/[locale]/services/[slug]/page.tsx`
- `app/[locale]/services/page.tsx`
- `app/manifest.ts`
- `app/robots.ts`
- `app/share-image/route.tsx`
- `app/sitemap.ts`

Динамические параметры раскрыты из активных услуг, landing pages, sitemap, GSC и каталога демо-проектов. Неограниченные неизвестные slug не перечисляются; проверяются репрезентативными 404. API отсутствует; формы используют Server Actions.
