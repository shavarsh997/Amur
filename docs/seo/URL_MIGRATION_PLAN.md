# План URL и миграций

## Сохраняемые постоянные редиректы

Эти правила уже существовали до текущего задания. Новых слияний на основании неполной GSC-выгрузки не вводим. Статус 308, тот же язык, query сохраняется; конечный URL имеет self-canonical и включён в sitemap.

| Исходный путь (каждый из 5 языков) | Конечный путь | Причина |
| --- | --- | --- |
| services/house-construction-yerevan | services/house-construction | существующая консолидация строительного интента |
| services/complete-house-construction-yerevan | services/house-construction | существующая консолидация строительства под ключ |
| services/interior-design-yerevan | services/interior-design | существующая географическая вариация дизайна |
| services/commercial-renovation-yerevan | services/commercial-construction | существующая консолидация коммерческих помещений |
| renovation-price-per-square-meter-yerevan | prices | стоимость м² раскрывается на странице цен |
| / | /hy | постоянная языковая главная |

Proxy нормализует slash/домен/alias вместе. Проверка опубликованного сайта 26.10.2026 (`LIVE_REDIRECTS.json`) выявила дополнительные хостинговые переходы перед proxy. Для `/ru/renovation-price-per-square-meter-yerevan/?audit=seo`: HTTP без www → HTTPS без www → HTTPS с www → `/ru/prices?audit=seo` (три 308, затем 200). HTTPS без www и HTTP с www дают два перехода; canonical HTTPS/www — один. Query сохраняется, циклов и ошибок нет. Настройка домена Vercel требует отдельного изменения при релизе: если оба домена обслуживает приложение, proxy уже умеет объединять www, slash и старый путь. Принудительный HTTPS на платформе может сохранять отдельный шаг. Редиректы не удалять после исчезновения исходников из sitemap.

| Группа | Возможное решение | Что переносить, если решение подтвердится | Риск |

Обновление 28.10.2026: пользователь разрешил обоснованные консолидации. Эти страницы сохранены из-за различия намерений и недостатка данных query + page/backlinks, а не из-за отсутствия разрешения. Они продолжают отдавать 200 и self-canonical. Низкий трафик не используется как довод удаления. Если необходимость слияния будет доказана: перенести уникальные блоки, установить прямой постоянный 301/308, переписать внутренние ссылки и карту интентов, убрать исходник из sitemap/hreflang, проверить 5 языков, query и slash, затем мониторить индексацию. Подробный вывод — DEEP_AUDIT_2026-10-28.md.

## Уже неопубликованные материалы

`/{locale}/projects`, демо-slugs проектов и пустые blog-маршруты не должны выдавать вымышленные кейсы. Существующие 404 сохраняются. Возможные исторические URL из GSC учитываются в инвентаре как INVESTIGATE: проверить ссылки/URL Inspection, прежде чем выбирать редирект. Это не новые удаления.

## Выпуск и откат

Изменения локальны. Перед выпуском: lint/typecheck/unit/build, production HTTP crawl, мобильный сценарий, проверка окружения GA4/Telegram без раскрытия секретов. Внешнюю тестовую заявку отправляет владелец после релиза. Выпуск через существующий Vercel/Git процесс; production из preview с SITE_NOINDEX=true не продвигать. Откат — вернуть предыдущую версию кода и пересобрать в production environment. Редиректы сохранять, если отдельная миграция не откатывается осознанно.
