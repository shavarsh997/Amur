1. Все **132 сформированные HTML-страницы** имеют тот же состав маршрутов и
   точное совпадение title, meta, canonical/hreflang, H1–H3, основного текста,
   JSON-LD и адресов ссылок. Декоративный SVG и скрипты исключены из сравнения
   видимого текста.
2. HTTP-проверка **120 URL из sitemap** прошла: статус 200, один H1, уникальные
   title/description, индексируемость, robots.txt, X-Robots-Tag, canonical,
   языковые ссылки, внутренние ссылки, структурированные данные и share image.
   Дополнительно прошли 50 вариантов устаревших URL, 3 редиректа со слешами и
   15 проверок настоящих 404.
3. Основной текст присутствует в исходном HTML и не требует прокрутки, загрузки
   анимации или выполнения JavaScript для появления. Начальные CSS-стили
   не скрывают основной контент. `aria-hidden` относится к декоративным SVG.
4. Новые библиотеки, видео, WebGL, внешние скрипты и изображения для анимации
   не добавлялись. Имеющиеся фотографии сохранились; их `sizes` адаптированы
   к новой компоновке. Их фактический сетевой объём в таблицу ниже не входит.
5. Сборка и проверка TypeScript прошли. В production-браузере заголовок видим,
   фотографии загружаются, ошибок консоли нет. На 390 px нет горизонтального
   переполнения; хедер остаётся высотой 65 px, а миниатюра — 44 px. Контент
   начинается сразу под хедером и не закрыт отдельной анимационной полосой.
6. Изменение SEO-проверяющего скрипта просмотрено отдельно: вместо ошибочного
   требования одинакового переведённого адреса во всех языках он сравнивает

   Production-разметка организации не менялась. Дополнительное независимое
   сравнение HTML также не обнаружило различий JSON-LD.

## Измеримый компромисс: вес и отрисовка

Русская главная, gzip level 6. КБ ниже — десятичные, 1000 байт. Для JavaScript и
CSS суммируются уникальные файлы, указанные в HTML; кэш между страницами не
учитывается. Это сравнение объёма файлов, а не замер времени загрузки.

| Ресурс                                  | До анимаций |   Сейчас |             Разница |
| --------------------------------------- | ----------: | -------: | ------------------: |
| HTML, включая встроенные данные Next.js |     40,7 КБ |  50,4 КБ |             +9,8 КБ |
| JavaScript                              |    188,9 КБ | 190,1 КБ |             +1,3 КБ |
| CSS                                     |     10,1 КБ |  12,9 КБ |             +2,8 КБ |
| Всего, без изображений                  |    239,6 КБ | 253,4 КБ | **+13,8 КБ / 5,8%** |

Для главных страниц пяти языков прирост составляет 13,2–13,9 КБ. В проверенных
русских страницах калькулятора, контактов и строительства дома — 12,5–13,4 КБ.

Несжатый HTML русской главной вырос с 247 602 до 322 342 байт. Количество HTML/SVG
элементов — с 628 до 963, в том числе добавлено 306 SVG-элементов. Основная причина:
две серверные копии сцены для десктопа и хедера; CSS показывает только одну.
Скрытая копия не рисуется, но её разметка всё равно передаётся и разбирается.

Контроллер использует пассивный обработчик прокрутки, объединяет обновления через
requestAnimationFrame, не запускает постоянный цикл в простое и поддерживает
reduced motion. Основное движение меняет transform/opacity без перестройки
размеров контента. При этом изменение заливок, SVG-линий и фильтр насыщенности
также требуют работы от браузера. Поэтому утверждать, что нагрузка равна нулю,
нельзя. Новая компоновка и `sizes` могут менять выбранный размер фотографии и
элемент LCP на отдельных разрешениях.

## Что не доказано и что стоит проверить после публикации

Этот аудит не измерял Lighthouse Performance, LCP, INP или CLS с эмуляцией
медленного телефона. Данные Search Console / CrUX для текущей версии в этом
аудите не проверялись. Поэтому вывод «позиции и Core Web Vitals точно не изменятся»
был бы необоснованным.

После публикации нужно сравнить мобильные LCP, INP и CLS с прежней версией на
главной, странице услуги и калькуляторе. Если появится ухудшение, первым кандидатом
на оптимизацию будет повторная SVG-разметка и упрощение сцены для мобильного
хедера. На основании текущих проверок срочный откат анимаций не требуется.

Google учитывает Core Web Vitals, но хорошие значения сами по себе не гарантируют
высоких позиций: [Google Search Central — Page experience](https://developers.google.com/search/docs/appearance/page-experience).
Наличие текста и обычных ссылок в серверном HTML соответствует рекомендациям
для JavaScript-сайтов: [Google Search Central — JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics).
О влиянии анимаций на смещения макета: [web.dev — Optimize CLS](https://web.dev/articles/optimize-cls).
