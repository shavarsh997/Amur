# Decisions

- 2026-11-22 — Маркетинговый агент — изолированный модуль `marketing-agent/` без npm-зависимостей (Node 22 strip-types), исключён из сборки сайта.
- 2026-11-22 — Репозиторий публичный: аналитика, отчёты, снимки, ledger и память хранятся в `~/Library/Application Support/shinex-marketing/`; секреты — gcloud ADC и macOS Keychain.
- 2026-11-22 — Только чтение для Google Ads/GA4/GSC; изменения рекламы — предложения на подтверждение владельца.
- 2026-11-22 — Расписание локальное (Claude desktop scheduled tasks), а не облачное: облако не видит локальные токены, переносить refresh-токен в облако небезопасно.
- 2026-11-22 — Задание считается выполненным за дату даже при частично недоступных источниках; после исправления доступа — `--force`.
- 2026-11-22 — Weekly берёт GSC до «сегодня − 3 дня» (задержка данных); monthly — прошлый календарный месяц.
- 2026-11-22 — Параметрические URL (`?scenario=`), canonical которых указывает на чистый путь, не считаются SEO-проблемой.
- 2026-11-22 — Форма заявки: обязательны только имя и телефон: большинство начавших заполнение не доходило до отправки. Остальное уточняет менеджер.
- 2026-11-22 — Первый GA4 page_view несёт allowlist gclid/gbraid/wbraid/utm_source/utm_medium/utm_campaign (с проверкой символов) и только origin внешнего реферера; остальные события без query. Сравнивать стандартные source/medium GA4 через эту дату нельзя.
- 2026-11-22 — `priceRange` в Organization не публикуем: стартовая ставка относится только к работам по ремонту, на уровне компании её прочтут как цену всех услуг.
- 2026-11-22 — llms.txt не добавляем: поисковые системы его не используют, AI-ответы опираются на индекс и внешние сигналы (GBP, отзывы, каталоги).
- 2026-11-22 — **Google Ads: армянские запросы ловим армянскими ключевыми словами, но объявления и посадочные — на русском.** Причина: Google Ads отклоняет армянский текст («Неподдерживаемый язык»). Ставки «Клики» с лимитом CPC до накопления реальных заявок (≥15) — без данных о конверсиях автостратегии не включаем. Микроконверсии (клики WhatsApp/телефон) исключены из целей тестовой кампании.
- 2026-11-25 — **Реклама «только в AI-поиске Google» невозможна**: отдельного таргетинга AI Overviews/AI Mode нет, AI Mode-реклама — тест в США. Приближение: поисковая кампания с AI Max и широким соответствием (кандидаты на показ в AI Overviews), Армения в режиме «присутствие или интерес» для зарубежной аудитории. Отдельного отчёта по AI-показам нет — оценивать только по заявкам.
- 2026-11-25 — **Доверие строим на подтверждённых условиях работы, а не на кейсах**: портфолио и отзывов пока нет, выдумывать их нельзя. Первый объект с разрешения клиента — первый кейс.
- 2026-11-25 — **Калькулятор ремонта показывает сумму сразу, без контактов** (площадь × тариф из `renovationPriceTiers`, материалы отдельно). Срок показываем только для новостройки 55–65 м² (единственный подтверждённый ориентир), иначе «уточним после замера».
- 2026-11-25 — **Только комплексный ремонт**: вариант «Отдельные работы» убран из формы (сервер ещё принимает старое значение `separate-works`), страницы сантехники/электрики/косметики оставлены для SEO с пометкой «в составе комплексного ремонта».
- 2026-11-26 — **На армянском мелкие подписи без капса и разрядки** (`:lang(hy) .uppercase` в `app/globals.css`, на всём сайте): армянский капс в разрядку плохо читается.
- 2026-11-26 — **Главная на телефоне: сначала обращение и цена, потом подробности.** Кнопка обращения должна помещаться в первый экран 375×812 над нижней панелью контактов; блоки, повторяющие одни и те же обещания, на главной не дублируем.
- 2026-11-26 — **SHINEX позиционируется как строительная компания, ремонт квартир — одна из услуг** (решение владельца). Заголовок главной «Строительство, ремонт и дизайн в Армении», картинка — здание; в общих блоках (первый экран, «Почему SHINEX», «О компании», описание GBP) только условия, общие для всех услуг: фиксированная цена, оплата по этапам без аванса, гарантия 12 мес., бесплатный выезд завтра, ответ за 15 мин, своя команда 10+ лет. «От 60 000/м²», «смета за 1–2 дня», «только комплексный ремонт» — только на страницах ремонта.
