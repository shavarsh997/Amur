Изменения внесены в код и проверены в локальном production build через настоящий браузер. Сохранены фирменные цвета, шрифты, тексты, изображения, маршруты, метаданные и поведение отправки заявок.

Каждая страница открыта при ширинах **375, 768, 1024 и 1440 px**: всего **480 сочетаний страницы и ширины**. Страницы прокручивались до конца для проверки нижних секций и загрузки изображений; сохранены полностраничные скриншоты и измерения DOM.

## Система отступов

Токены определены в `app/globals.css` через существующий Tailwind `--spacing` (4 px). Новые произвольные значения для отдельных страниц не используются.

| Назначение                                           | <640 px | 640–1023 px | 1024–1279 px | ≥1280 px |
| ---------------------------------------------------- | ------: | ----------: | -----------: | -------: |
| `--container-gutter` — поля контейнера               |      16 |          24 |           32 |       40 |
| `--section-space` — вертикальные поля обычной секции |      48 |          64 |           80 |       80 |
| `--section-gap` — расстояние между группами контента |      32 |          40 |           48 |       48 |
| `--panel-space` — внутренние поля крупной панели     |      20 |          24 |           32 |       32 |

Tailwind-утилиты: `py-section`, `space-y-section-gap`, `gap-section-gap`, `p-panel`. Для компактных элементов используются существующие `gap-3`, `gap-4`, `gap-6`, `p-5`, `p-6`, `mt-3`, `mt-4`, `mt-6` в зависимости от роли. Секции с одинаковым фоном могут делить общий интервал, чтобы два отступа не суммировались без необходимости.

`layout-region` задаёт контейнер для вложенной сетки. `local-grid` становится двухколоночной при собственной ширине 560 px; `local-grid-three` — трёхколоночной при 800 px. Поэтому форма или контактная панель не наследует неподходящее число колонок только из ширины окна. Карточки услуг, преимущества hero, каталог и CTA используют свои пороги по доступной ширине.

## Результаты проверок

- Финальная матрица: **480/480 без горизонтального переполнения страницы, выходящих за экран элементов и незагруженных изображений**.
- Повторная проверка длинных мобильных текстов: **120/120 без переполнения**.
- `npm run build` — успешно.
- `npm run lint` — успешно.
- `npm run typecheck` — успешно.
- `npm run calculator:check` — успешно: сценарии строительства и дизайна, локализации, отдельный контактный сценарий ремонта.
- `npm run leads:check` — успешно: валидация и тестовый транспорт Telegram.
- `npm run analytics:check` — успешно.
- `npm run seo:check` — успешно: 120 URL и 25 редиректов.
- Prettier для изменённых исходных файлов и `git diff --check` — успешно.

Реальные заявки не отправлялись. Серверная отправка проверена существующими тестами с подменённым транспортом; браузерная проверка завершалась перед отправкой. Аудит выполнен в браузере приложения; отдельная проверка на физических iOS/Android-устройствах и во всех браузерных движках не проводилась.
