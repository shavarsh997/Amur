# Known issues / ловушки

- **Node 22.14: `node --test test/` не обходит папку.** Использовать glob: `node --experimental-strip-types --test 'test/*.test.ts'`.
- **Коннекторы должны быть `async`**, иначе неверный аргумент бросает синхронно, а не rejected promise.
- **GA4-ресурс общий для нескольких сайтов владельца.** Любой отчёт GA4 без фильтра hostName неверен.
- **Сайт очищает `page_location` и `page_referrer`** (`lib/analytics.ts`). Следствие: gclid и referrer теряются, органика и Google Ads попадают в Direct; стандартные каналы GA4 нельзя использовать для оценки рекламы и SEO.
- **Ключевые события GA4 содержат микроконверсии** (`whatsapp_click`, `phone_click`) и дубли `shinex_*` — двойной счёт; Ads оптимизируется на клики по кнопкам, а не на заявки.
- **Google Ads API**: без Explorer access GCP-проекта любой запрос к не-тестовому аккаунту → 403 `ACTION_NOT_PERMITTED`. Developer token в 2026 не нужен. Версия API: v23 (v22 — `UNSUPPORTED_VERSION`).
- **google-ads-mcp не ставится на Python 3.15** (конфликт зависимостей) — ставить `pipx install --python python3.12 google-ads-mcp`.
- **PageSpeed API не принимает OAuth-токен с cloud-platform**, анонимная квота общая и быстро исчерпывается → нужен API-ключ в Keychain (`psi-api-key`).
- **OAuth-приложение в статусе Testing** выдаёт refresh-токен на 7 дней — держать In production.
- **Google-аккаунты:** GA4 и Ads доступны не всем владельцам GSC; агент должен авторизоваться аккаунтом из приватного `ACCOUNTS.md` (каталог данных).
- **`/` отдаёт 308 → `/hy`** — это норма; редирект считается проблемой только для URL из sitemap.
- **Задачи по расписанию в обычном режиме разрешений останавливаются на первой команде Bash** и в списке запусков могут показываться как «succeeded», хотя прерваны (`error_during_execution`). Нужен «Always allow» в первом ручном запуске (одобрения сохраняются на задаче) или режим разрешений задачи. Команды в промптах — одиночные, без `cd`/`export`/`&&`, чтобы одобрение совпадало. Агент сам правила разрешений не меняет.
- **Search Console не содержит платных кликов Google Ads** — рост в GSC органический; не путать с ростом сессий в GA4.
- **Название карточки Google Business Profile написано с кириллической «Х»** — поиск по латинскому «SHINEX» её не связывает с сайтом; рядом в брендовой выдаче есть не связанная компания с похожим названием. Исправляет только владелец в GBP.
- **form_submit ≠ заявка.** form_submit шлётся до серверной валидации; заявка — только generate_lead (сервер подтвердил доставку). Ошибки — form_error с error_type.
- **В GSC встречаются диалоговые запросы** (просьбы показать фото работ, узнать цену, руководителя) — похоже на Google AI Mode. Это сигнал, каких фактов о компании не хватает, а не ключевые слова для страниц.
- **Армянский язык не поддерживается в объявлениях Google Ads.** Объявление на армянском (или с армянской целевой страницей) отклоняется: «Неподдерживаемый язык». Армянские ключевые слова допустимы, текст объявления и посадочная — на русском/английском. Кроме того, редактор считает армянские буквы за 2 символа.
- **В мастере поисковой кампании (2026) нет языкового таргетинга** — язык определяет Google; язык показа задаётся языком ключевых слов и объявлений. Название кампании, введённое на первом шаге, может не сохраниться («Не удалось сохранить изменения») — проверять в сводке и переименовывать после публикации.
- **Meta Ads Manager: клавиша Escape в редакторе кампании открывает окно «Опубликовать черновики?»** — не нажимать Escape; закрывать попапы кликом. В аккаунте висят чужие черновики, общая кнопка «Проверить и опубликовать (N)» опубликует и их.
- **Meta: бюджет на весь срок требует даты окончания группы**; без неё молча откатывается в дневной. Расписание показа (часы/дни) доступно только с бюджетом на весь срок; строгий дневной лимит при этом не задаётся — Meta распределяет неравномерно, гарантирован только общий потолок.
- **Мгновенные формы Meta не поддерживают армянский язык интерфейса** — системные подписи (имя, телефон, кнопки) будут на выбранном языке (ставим русский), свои тексты и вопросы пишем по-армянски.
- **Загрузка файлов в Ads Manager через Claude in Chrome**: кнопка «Загрузить» открывает системный диалог; перехватить `HTMLInputElement.prototype.click` для `type=file`, загрузить файл через file_upload в пойманный input, затем вернуть исходный метод. WebP конвертировать в PNG (`sips -s format png`).
- **Meta: тип оптимизации кампании с бюджетом кампании фиксируется после публикации.** Переделать «форму» в WhatsApp внутри той же кампании нельзя (#1885760) даже после удаления старых групп — нужна новая кампания (дублирование кампании с последующей сменой места конверсии в группе).
- **Meta: при дублировании группы сбрасываются даты (на «сейчас») и локация (на страну из настроек аккаунта)**, а также платформы/плейсменты — после копирования проверять «Проверка» группы целиком.
- **Репозиторий лежит в `~/Desktop`, который синхронизирует iCloud с «Оптимизацией хранилища».** iCloud выгружает редко используемые файлы `.git` (флаг `dataless`), и git падает с `cannot lock ref 'ORIG_HEAD' … Operation timed out`. Проверка: `find .git -flags +dataless | wc -l`. Быстрое лечение: `rm .git/ORIG_HEAD`. Надёжное: держать репозиторий вне iCloud (например, `~/Developer`).
- **Meta при дублировании объявления/загрузке медиа включает ИИ-улучшения и предлагает подмешать новую картинку в активные объявления** — после копии проверять «Улучшения креатива» и «Ключевые улучшения» (должно быть 0/7 и 0/4) и снимать галочки «Опубликуйте загруженный медиафайл в текущих активных объявлениях».
- **Google Ads: английское объявление с английской посадочной (/en/…) в кампании с гео Армения было автоматически отклонено «Неподдерживаемый язык»** (25.11.2026), хотя страница `lang="en"` и без редиректов; русское в той же кампании допущено. Похоже на ложное срабатывание — решается апелляцией. Шаблон новой группы объявлений копирует тексты и URL предыдущего объявления — заменять все поля.
- **Клик WhatsApp ≠ переписка.** wa.me открывает чат с готовым текстом, но человек часто его не отправляет; whatsapp_click нельзя считать заявкой — реальные обращения только из журнала воронки (`cli.ts funnel add`).
- **Встроенный браузер Claude не открывает localhost** — проверять собранный сайт через `npx next start -p <порт>` + curl.
- **Мелочи калькулятора ремонта (не исправлены):** `lib/calculator/renovation-quote.ts` принимает «1e3»/«0x3C» через `Number()`; площадь в тексте округлена до 2 знаков, сумма — по полному значению; `calculator_complete` срабатывает на первой допустимой площади во время ввода; «Перезвоните мне» открывает форму без параметров расчёта. В немецких текстах встречаются и «Jerewan», и «Eriwan».
- **Общая папка `.next`**: параллельные `next dev`/`next start` в репозитории перезаписывают `.next`, и страницы отдаются без стилей. Перед замерами — одна сборка и один сервер; замер вёрстки — headless Chrome по CDP (`--remote-debugging-port`).
- **Неиспользуемые после упрощения главной:** `components/sections/specialized-services.tsx`, `components/sections/service-area.tsx`, CSS `.technical-services*` и `.principles`, `homeContent.*.serviceArea`; шаги калькулятора `renovation-extras-step.tsx` и `wall-works-step.tsx` не рендерятся.
